# BJE Portfolio Lab

자산배분 대시보드입니다. 허용 GitHub 대상은 **hahajongha/bje**이며 확인된 기본 브랜치는 **main**입니다. 다른 프로젝트 코드나 설정을 가져오지 않고 새로 작성했습니다.

## 기능

- 현재 비중, 최소분산, 목표수익률, 최대 Sharpe 비교
- 효율적 경계선과 Sharpe 그라데이션의 최대 2,400개 조합 탐색
- SAA 자산군·개별 자산 제약, TAA 두 비중안 및 가정 비교, 각각 2개 저장 슬롯
- 비중 변경, 위험기여 비중, 정규모형의 1년 실현수익률 범위
- 자산별 기대수익률·변동성·비중·상관계수·무위험금리 편집
- 원화 총수익 추이, 1년/3년/5년 표시
- 브라우저별 가정 저장, JSON 스냅샷 가져오기, 반응형 화면
- 리스크 탭: 선택 포트폴리오의 변동성, 부호 있는 위험기여, 분산효과 비율, 1년 수익률 범위
- 환헤지 탭: 모니터링 / 환헤지모델A / 환헤지모델B, 4개 통화의 만기별 비용과 환 변동성

정적 HTML/CSS/ES modules이며 외부 JavaScript·폰트·CDN 의존성이 없습니다. `dist/`를 정적 호스팅으로 제공하면 됩니다. 웹 서버 없이 HTML을 직접 여는 `file://` 실행은 지원하지 않습니다.

## 데이터 경계

**공개 소스의 `dist/data.json`과 `dist/demo-data.mjs`에는 가상 입력만 있습니다.** 실제 Drive Excel, 실제 수익률, Drive 파일 ID와 접근 토큰은 이 소스 묶음에 없습니다. 실제 데이터가 들어간 배포는 비공개를 유지해야 합니다. 실제 데이터를 공개 `dist/data.json`에 덮어써 커밋하지 마십시오.

스냅샷을 읽지 못하면 예시 가정으로 시작하고 오류 안내를 보여 줍니다. 자동 Drive 동기화 기능은 없습니다. JSON 가져오기는 브라우저 메모리에서 처리하며 업로드하지 않습니다. 가져온 스냅샷은 새로고침하면 기본 데이터로 돌아갑니다. 사용자가 적용한 투자 가정만 해당 스냅샷별로 localStorage에 저장됩니다.

## 계산

`dist/portfolio.mjs`의 공개 함수:

- `covariance(assets, correlation)` — 연간 %p² 공분산
- `stats(weights, assets, cov, rf)` — 수익률, 변동성, Sharpe, 부호 있는 위험기여
- `optimize(assets, cov, rf, target)` — minVol/maxSharpe/target/frontier
- `validateInputs(assets, correlation)` — 유한수·대칭·상관범위·양의 정부호 검증

`assets.mu`, `assets.vol`, `rf`, `target`은 연간 퍼센트 단위입니다(5 = 5%). 비중은 소수입니다(0.2 = 20%). 무차입·공매도 금지·비중 합 100%입니다. 기본 계산은 자산별 상한이 없으며, SAA를 적용하면 자산·그룹별 최소/최대 비중을 추가합니다. 2~8개 자산을 지원합니다. 변동성 0과 특이 상관행렬은 조용히 보정하지 않고 거절합니다.

월별 단순수익률 산술평균 × 12, 표본공분산 × 12로 연율화합니다. 이는 월별 자기상관을 무시한 근사입니다. 효율적 경계선은 최소분산 포트폴리오 이상의 수익률 구간입니다. 불가능한 목표는 `null`을 반환합니다. 모든 초과수익률이 0 이하이면 최대 Sharpe는 최선의 단일자산을 선택합니다.

1년 구간은 정규분포 가정의 실현수익률 범위이며 기대수익률 추정치의 신뢰구간이 아닙니다. 과거 평균은 전망이 아니고, 표본 내 최적화는 표본 외 성과를 입증하지 않습니다. 비중과 2.50% 무위험금리는 초기 예시입니다.

## 원자료 변환

Python `numpy`, `openpyxl`을 사용하며 Excel을 읽기만 합니다. 제공기관의 add-in을 새로고침하지 않습니다.

```bash
python scripts/build_data.py --info /private/data_info.xlsx --bb /private/data_bb.xlsx --as-of 2026-10-15 --months 60 --output /private/portfolio.json
```

공개 저장소 안에 원본 또는 결과를 두면 실행을 거절합니다. 생성한 JSON은 CMA 탭의 JSON 불러오기에서 가져올 수 있습니다.

| 자산 | 파일 / 시트 / 열 | 통화 처리 |
| --- | --- | --- |
| 국내 종합채권 | data_info / DailyRate / JO | KIS 총수익, 원화 |
| 국내 주식 | data_bb / D / FX | KOSPI 총수익, 원화 |
| 미국 주식 | data_bb / D / FW 및 BB | S&P 500 USD 총수익 × USDKRW |
| 미국 국채 | data_bb / D / GP | IEF 총수익, 원자료 CURR=KRW |
| 미국 투자등급 | data_bb / D / GR | LQD 총수익, 원자료 CURR=KRW |
| 달러 단기채 | data_bb / D / GT | BIL 총수익, 원자료 CURR=KRW |

ETF 세 열은 이미 원화 입력이므로 환율을 다시 곱하지 않습니다. 헤더·통화 요청 수식이 바뀌면 변환을 거절합니다. 같은 날짜의 공통 값으로 월별 마지막 관측을 선택하며 현재 진행 중인 월은 제외합니다. 보간하지 않습니다. 달력상 월말에서 7일을 초과한 관측이나 빠진 월은 거절합니다. 국가별 거래시간과 휴장일 반복값은 남을 수 있습니다. 데이터 제공기관의 독립 원자료 대조는 미수행입니다.

실제 JSON 스키마는 `assets[].annualMean/annualVol/currentWeight` 소수 단위, `correlation` 2차원 배열입니다. `meta.periodStart/periodEnd/observations`가 표본을 나타냅니다. `monthly.returns`는 `monthly.dates`와 대응하고, `monthly.base100`은 초기 관측을 포함하는 `monthly.baseDates`와 대응합니다. 모든 2차원 시계열 배열은 시점 × 자산 순서입니다.

## 화면 문구 원칙

메뉴·제목·수치 라벨은 간결하게 유지하며 새로운 문장형 설명 주석은 추가하지 않습니다. 메뉴 순서는 `PORT → RISK → CMA → HEDGE → FX`이며 작은 메뉴 아이콘과 숫자 번호는 표시하지 않습니다. 투자 가정 메뉴는 `CMA`, 해당 화면 제목은 `Capital Market Assumption`을 사용합니다. 공통 상단 문구·내보내기/편집 버튼·데이터 안내 박스와 사이드바 하단 Workspace 표시는 제거했습니다.

## 리스크와 환헤지

리스크는 포트폴리오/CMA의 현재 가정을 사용합니다. 위험기여 비중은 부호를 보존하며 합계는 100%, 변동성 기여는 %p이며 합계는 포트폴리오 변동성입니다. 분산효과 비율은 비중 가중 개별 변동성 합계를 포트폴리오 변동성으로 나눈 값입니다. 68/90/95/99% 범위는 기존 카드와 같은 정규분포 모형입니다.

환헤지 모니터링은 USDKRW, AUDKRW, JPYKRW, EURKRW 순서로 3M·6M·12M 비용, 세 만기의 단순평균, 환 변동성을 표시합니다. 양수는 수취, 음수는 지급입니다. 공개 코드에는 환헤지 관측값을 넣지 않았으며, 첨부 이미지의 과거 숫자를 최신 시장값으로 복제하지 않았습니다. 미연결·누락 값은 `—`이고 세 만기 중 하나라도 누락되면 평균도 `—`입니다. 모델A/B는 세부 메뉴만 구성했으며 산식·데이터가 지정되기 전에는 `모형 미설정`으로 표시합니다.

환헤지의 `데이터 불러오기`는 아래 형태의 JSON을 받습니다. 기존 포트폴리오 JSON의 `fxHedge` 필드에 같은 객체를 넣어 CMA에서 함께 불러올 수도 있습니다. 불러온 값은 현재 화면 메모리에만 적용되며 새로고침 또는 다른 포트폴리오 스냅샷 적용 시 초기화됩니다.

```json
{
  "unit": "annual_percent",
  "source": "사용자 스냅샷",
  "pairs": []
}
```

`pairs`의 각 객체 필드는 다음과 같습니다. 통화별 중복, 유효하지 않은 날짜·숫자·음수 변동성은 전체 불러오기를 거절하고 이전 값을 유지합니다.

| 필드 | 의미 |
| --- | --- |
| `currency` | USDKRW / AUDKRW / JPYKRW / EURKRW |
| `asOf` | 비용 기준일 YYYY-MM-DD |
| `hedge3m`, `hedge6m`, `hedge12m` | 연율 퍼센트. 5는 연 5%. 누락 시 null |
| `fxVol` | 연환산 환율 변동성 %, 누락 시 null |
| `volAsOf` | 변동성 기준일. 생략 시 asOf |
| `volPeriod` | 변동성 추정기간 라벨. 생략 시 기간 미지정 |
| `aggregation` | snapshot 또는 median_5_business_days. 생략 시 snapshot |

`median_5_business_days`는 입력자가 이미 집계한 최근 5영업일 중앙값이라는 표시이며, 앱이 원시 일별 자료로 계산하거나 검증하는 값은 아닙니다. 헤지 평균과 환 변동성은 포트폴리오 공분산이나 기대수익률에 자동 반영하지 않습니다.

기능 검증은 22개 Node 계산·DOM 대역 테스트를 사용했습니다. 실제 브라우저 렌더링·Windows ClearType 설정은 검증하지 못했습니다. 글꼴은 로컬 한글 시스템 글꼴을 우선 사용하고, 크기·두께·명암을 조정했으며 디스플레이 해상도 자체를 변경하지 않습니다.


## Sharpe 조합 탐색과 SAA / TAA

기본 분류는 국내시가, 국내장부, 해외시가, 해외장부, 국내주식, 해외주식, 대체투자의 7개입니다. 앞 4개는 `group: bond`, 주식 2개는 `equity`, 대체투자는 `alternative`입니다. 기존 6개 자산의 실제 스냅샷은 입력 분류를 유지하며, 없는 장부·대체 시계열을 생성하거나 복제하지 않습니다. 신규 JSON에 그룹 제약을 적용하려면 `assets[].group`을 지정합니다. 미분류 자산에는 개별 비중 범위만 적용됩니다.

공개 기본값은 모두 가상 가정입니다. 기존 대응 자산 4개의 수익률·변동성·상관관계를 보존했고, 추가 장부·대체 가정의 출처는 `meta.notes`에 기록했습니다. 장부 분류만으로 시장위험이나 경제적 위험이 낮다고 판단한 결과가 아닙니다. 기존 실제자료 생성기는 6개 자산 출력을 유지합니다.

- 차트 점의 색상은 `(기대수익률 − 무위험금리) / 변동성`인 Sharpe입니다. 색 범위는 현재 SAA/가정에서 다시 계산하므로 서로 다른 설정의 동일 색상이 동일 Sharpe를 뜻하지 않습니다.
- 점 클릭 또는 Sharpe 순서의 조합 슬라이더로 비중·위험기여를 확인합니다. 점은 결정적 난수로 만든 실행 가능한 예시 조합이며 확률분포·미래 성과 표본이 아닙니다. 고정 비중의 실행 가능 집합은 1점으로 표시합니다.
- SAA는 채권·주식·대체 및 개별 자산의 최소/최대 비중입니다. 기본 범위는 모두 0~100%입니다. `제약 적용`은 경계선, 최소분산, 최대 Sharpe, 목표수익과 조합 구름을 함께 갱신합니다. 실행 불가능한 제약은 이전 적용 상태를 보존하고 거절합니다.
- TAA는 비중1·비중2와 공통 기대수익률·변동성을 편집합니다. 두 비중의 합계는 각각 100%여야 하며 SAA 위반은 `SAA 제약 밖`으로 표시합니다. 위반하는 비교안도 확인할 수 있지만 경계선 계산의 제약을 완화하지 않습니다. 가정은 CMA와 공유합니다.
- SAA/TAA 각각 2개 슬롯을 브라우저에 저장합니다. `불러오기`는 입력 초안에만 반영하며 적용 버튼을 눌러 계산에 반영합니다. 한 영역의 불러오기·적용은 다른 영역의 미적용 초안을 보존합니다.

`dist/allocation.mjs`는 `defaultPolicy`, `validatePolicy`, `satisfiesPolicy`, `optimizeAllocation`, `samplePortfolios`를 제공합니다. 제약 최소분산·목표수익은 실행 가능 활성집합 QP, 양의 최대 Sharpe는 효율적 경계선 위 수치 탐색을 사용합니다. 모든 실행 가능 초과수익이 0 이하이면 제약 다면체 꼭짓점을 비교합니다. `returnRange`는 제약하의 실행 가능 수익률 범위입니다. 수치 허용오차를 사용하며 숨은 정규화나 제약 완화는 없습니다.

2026-10-16 검증: Node 계산/DOM 대역 36개, 해석해·별도 격자 대조, 7자산 난수 SPD/제약 40개에 대한 SciPy SLSQP 120개 목적함수 대조를 수행했습니다. 별도 SciPy 경로와의 최대 차이는 분산 2.14e-11 %p², Sharpe 9.29e-13이었습니다. 재현 명령은 `python scripts/verify_allocation.py`이며 NumPy·SciPy가 별도로 필요합니다. 이는 계산 검증이고 가상 입력의 실증 검증은 아닙니다.

생성한 SVG의 800px/360px 래스터 확인은 수행했습니다. 좁은 차트의 자산명은 겹침 방지를 위해 생략하고 점 제목·자산 구성표에서 확인하도록 했습니다. 실제 브라우저 실행 파일 다운로드 실패로 전체 페이지 배치·네이티브 입력·기기별 글꼴 렌더링은 검증하지 못했습니다.


## USDKRW 3국면 환율모형

좌측 `환율모형`은 USDKRW 일별 로그수익률의 Gaussian Markov Switching 모형을 표시합니다. 추정은 Python, 화면은 정적 ES module로 분리되어 있으며 `데이터 불러오기`에서 실제 추정 JSON을 읽습니다. Drive 자동 갱신이나 브라우저 재추정은 없습니다. 실제 관측값과 추정 결과는 공개 저장소에 넣지 않으며 기존 데이터 경계를 유지합니다.

### 정의와 불확실성

- 관측식: `r_t = log(S_t / S_(t-1)) = mu[state_t] + sigma[state_t] * epsilon_t`, 표준정규 독립 충격.
- 전이행렬은 `P[i,j] = Pr(state_(t+1)=j | state_t=i)`로 행이 현재, 열이 다음 국면입니다. 세 국면은 추정 변동성 오름차순인 저변동·중변동·고변동이며 상승·하락 방향을 미리 강제하지 않습니다.
- scaled Hamilton filter / forward-backward와 다중 초기값 EM으로 국면별 평균·분산·전이확률·초기확률을 추정합니다. 분산 하한은 전체 표본분산의 0.5%, 각 국면의 기대 점유율 하한은 0.5%입니다. 수렴한 허용 후보 중 우도가 가장 큰 해를 선택하며 전역최적은 보장하지 않습니다. 모든 후보 미수렴 시 경고를 남깁니다.
- 현재 국면은 마지막 filtered probability입니다. 과거 확률은 전체표본에서 추정한 모수를 고정해 필터링한 값으로, 당시 이용 가능했던 정보만으로 모수까지 재추정한 실시간 결과가 아닙니다.
- 전망 평균은 Markov 경로별 로그정규 기댓값의 정확 재귀식으로 계산합니다. 단순히 평균 로그수익을 지수화한 값과 구분합니다.
- 기본 40,000개의 상태·충격 경로로 16/84, 5/95, 2.5/97.5 분위수의 68/90/95% 예측구간을 생성합니다. 국면별 충격분산과 미래 국면경로 불확실성을 모두 포함합니다. 누적 로그 표준편차는 정확한 1·2차 모멘트 재귀식으로 계산하여 시뮬레이션과 대조합니다.
- 구간은 추정모수를 고정한 조건부 미래 실현값 범위입니다. 평균추정치의 신뢰구간이 아니며 모수 추정·모형 선택·구조변화 불확실성은 미포함입니다. 21관측을 1개월로 근사하고 미래 날짜에서는 토·일만 제외하므로 12개월(252관측) 종료일은 달력상 1년 후와 다릅니다.
- 마지막 252관측은 별도 시간순 holdout으로 검사합니다. 이전 자료로만 모수를 추정·고정하고 실제 직전 관측까지 국면확률을 갱신해 다음 관측 환율의 RMSE/MAE와 예측구간 포함률을 평가합니다. 비교대상은 무드리프트 현물 랜덤워크이며, 이 일간 검증은 12·24개월 구간의 명목 커버리지를 입증하지 않습니다.

### 근거와 검증 범위

허용 저장소 `hahajongha/bje`에는 KG 모듈이 없어 KG 참조는 수행하지 못했습니다. 다른 저장소의 코드·지식그래프는 열지 않았습니다. 일반 모형과 필터의 근거는 [Hamilton, Regime-Switching Models](https://econweb.ucsd.edu/~jhamilto/palgrav1.pdf), 구현 참고는 [statsmodels 공식 Markov Switching 설명](https://www.statsmodels.org/stable/examples/notebooks/generated/markov_autoregression.html)입니다. 본 구현은 평균과 분산이 전환되는 3상태 로그수익률 모형이며 참고 예제의 시계열·모형을 복제한 결과가 아닙니다.

독립 검증 스크립트는 짧은 지평의 모든 상태경로를 열거하여 필터·smoother·전이 count·누적 로그 모멘트·환율수준 기댓값과 비교하고, Gaussian mixture CDF를 역산해 시뮬레이션 분위수를 대조합니다. 흡수국면과 동일국면 경계조건도 확인합니다. 브라우저 실행 파일 다운로드 실패로 전체 브라우저의 네이티브 파일 입력·레이아웃 검증은 수행하지 못했으며, Node의 실제 이벤트 로직/DOM 대역과 SVG 래스터 확인으로 범위를 구분합니다.

헤지 열의 하위 헤더는 `프리미엄`이며 연율·백분율 단위가 명시되어 있지 않습니다. 따라서 신규 입력은 `unit: source_value`로 보존하고 화면에 `원자료 단위`를 표시합니다. 숫자를 임의로 연율화하거나 % 단위를 붙이지 않습니다. 기존 `annual_percent` 환헤지 JSON은 기존 표시 방식을 유지합니다. FX 변동성만 연율 %이며 엔화 현물은 원/100엔입니다.

헤지 분포는 같은 날짜의 세 만기가 모두 존재하는 일별 단순평균으로 계산합니다. 최근 관측의 누락된 만기는 과거 값으로 메우지 않습니다. 기간 선택은 최대 조회 범위이며 차트에 실제 보유기간·관측수를 표시합니다. 환변동성 창 안에 누락된 날짜행이 있으면 수익률을 연결하지 않고 결측 처리합니다. 휴장일·동일가격 반복 관측은 원자료에 남아 있을 수 있습니다.

KIS 통계는 최근 60개 완결월의 단순수익률에서 산술평균 × 12, 표본표준편차 × √12로 계산합니다. CAGR은 월말 지수 비율을 연율화하며 MDD는 월말 관측 기준입니다. 월말 7일을 초과해 낡은 관측과 누락 월은 허용하지 않습니다. YTD는 직전 연말, 1년 수익률은 1년 전 같은 날짜 이하의 가장 가까운 관측을 사용합니다. 과거 실적은 투자 전망이나 7개 자산군 전체의 CMA 추정치가 아닙니다.

2026-10-16 검증: Node 계산·DOM 47개와 Python 추출 12개 통과. 별도 검증기는 XLSX XML을 직접 읽고 표준 `math`로 재계산하여 20개 시장지표, 61개 월말 지수, 1,892개 헤지 평균 이력을 대조했습니다. 숫자 2,040개·정확일치 필드 2,065개 통과, 최대 절대차 7.44e-15입니다. 파일 자체의 제공기관 정확성은 동일 원자료 공유로 인해 독립 검증된 것이 아닙니다. 생성 HTML의 전체 모듈·내장자료·탭 이벤트를 Node VM/DOM으로 실행하고 네트워크 요청이 없음을 확인했으며, SVG 차트 5개를 래스터로 확인했습니다. 브라우저 바이너리 다운로드 실패로 실제 브라우저의 파일 선택·전체 페이지 배치는 미검증입니다.

## 효율적 경계선 이동 비교

개별 자산점·차트 아래 자산 버튼·조합점·탐색 슬라이더·포트폴리오 카드를 선택하면 우측 자산 구성에 선택 비중, 효율적 경계선 목표 비중, 목표−선택 증감(%p)을 표시합니다. 개별 자산은 해당 자산 100% 포트폴리오입니다. 아래 기대수익·변동성은 현재 선택한 포트폴리오의 연율 값이며, 이동 목표 지표와 구분합니다.

기본 이동 기준은 선택 변동성을 초과하지 않는 SAA 내 최대 기대수익입니다. 대안 기준은 선택 기대수익 이상을 확보하는 SAA 내 최소 변동성입니다. 최소분산점보다 수익이 낮거나 최대수익 경계에 걸리면 동일 수익·위험이 정확히 유지되지 않을 수 있으므로 조건을 표시합니다. 기준을 충족할 수 없거나 선택 포트폴리오를 지배하지 못하면 목표·증감을 비워 둡니다. 목표는 조합 표본이 아니라 기존 제약 최적화기로 계산하며, SAA·CMA 변경 시 다시 계산합니다. 선택·비교만으로 현재 비중이나 저장된 TAA를 변경하지 않습니다.

검증 명령: `npm test`, `python scripts/verify_frontier_target.py`(별도 검증용 NumPy·SciPy 필요). 24개 난수 SPD/SAA 설정 × 3개 선택 포트폴리오 × 2개 이동 기준을 직접 제약 최적화와 대조합니다. UI smoke는 클릭·키보드 선택, 증감 항등식, SAA 변경 후 목표 해제, 선택 기대수익·변동성의 동기화를 검사합니다. 실제 브라우저 화면 검증은 실행 파일 다운로드 실패로 미수행입니다.
